SCENARIO: HotelStay Room Booking System (HotelSBS)
---------------------------------------------------------------

Tables:
  Guest     — guestID, Fname, Lname, Age, Phone, Email, Country
  Room      — roomID, roomType, pricePerNight, floorNum, availableSlots
  Booking   — bookingID, roomID, guestID, checkIn, numOfNights,
               checkOut (NULL if not yet checked out)

Assumption: Each room has a maximum of 3 active bookings (availableSlots).

---------------------------------------------------------------

---------------------------------------------------------------
Q2 — SELECT (No Bookings)
---------------------------------------------------------------
Write a SELECT that shows all guests who have never made a booking.
Columns: guestID | Fname | Lname | numOfBookings (= 0)

---------------------------------------------------------------
Q3 — SELECT with Aggregation
---------------------------------------------------------------
Write a SELECT that shows each room and its average actual stay
duration in nights. Only count completed bookings (checkOut IS NOT NULL).
Columns: roomID | roomType | AverageNights

---------------------------------------------------------------
Q4 — View
---------------------------------------------------------------
Create a view called CurrentGuests showing all guests currently
staying (checkOut IS NULL).
Columns: bookingID | Fname | Lname | roomID | roomType | ExpectedCheckOut
ExpectedCheckOut = checkIn + numOfNights (use DATE_ADD)

---------------------------------------------------------------
Q5 — Trigger ⭐
---------------------------------------------------------------
Create a trigger on the Booking table that fires AFTER UPDATE.
When checkOut changes from NULL to a date (guest checks out),
increase the room's availableSlots by 1 in the Room table.
Test with an UPDATE and verify availableSlots changed.

---------------------------------------------------------------
Q6 — Procedure
---------------------------------------------------------------
Create a procedure called MakeBooking that handles a new booking.
Inputs: roomID, guestID, checkIn, numOfNights

- If availableSlots = 0:
    do NOT insert, print "Booking failed! Room is fully booked."
- If available:
    insert the booking, decrement availableSlots by 1,
    print "Booking confirmed!"

Call it at least twice to demonstrate both outcomes.

---------------------------------------------------------------
Q7 — Advanced SELECT I
---------------------------------------------------------------
Show ALL guests and every booking they have made.
Guests with no bookings must still appear.
Columns: guestID | name_ (Fname + ' ' + Lname) | bookingID | roomID
Order by bookingID DESC.

---------------------------------------------------------------
Q8 — Advanced SELECT II
---------------------------------------------------------------
Show all guests currently staying (checkOut IS NULL).
Columns: guestName (Fname + ' ' + Lname) | roomType | ExpectedCheckOut

---------------------------------------------------------------
Q9 — Function I ⭐
---------------------------------------------------------------
The hotel charges 200 SEK per extra night when a guest stays longer
than originally booked.

Write a function GetOverstayFee(bookingID) that returns the fee,
or 0 if no overstay or not yet checked out.

Then write a SELECT using the function showing only guests who owe
a fee. Columns:
  bookingID | Fname | Lname | extraNights | totalFee

Only show rows where totalFee > 0.
Hint: extraNights = DATEDIFF(checkOut, checkIn) - numOfNights

---------------------------------------------------------------
Q10 — Function II
---------------------------------------------------------------
Create a function GetBookingCount(roomID) that returns the total
number of times a room has been booked.

Plug it into a SELECT showing ALL rooms ordered by booking count
descending. Rooms with zero bookings must still appear.
Columns: roomID | roomType | numOfBookings
